# Case Zero

Case Zero is a dark-themed detective investigation dashboard built with plain HTML, CSS, and vanilla JavaScript. The app presents a fictional missing-artwork investigation with a top navigation, case overview, suspect details, evidence archive, timeline reconstruction, and accusation workflow.

## Overview

This project is designed as a polished bug-hunt challenge app where contributors investigate a fictional case board, browse files, search evidence, and identify the culprit in a realistic detective UI.

## Features

- Top navigation with Overview, Cases, Suspects, Evidence, and Timeline
- Investigation overview dashboard
- Search and filtering for case files
- Suspect profiles with personal alibi and evidence references
- Evidence archive with review status
- Chronological reconstruction timeline
- Case detail and accusation flow
- Local browser persistence for notes and review state

## Run the app

For the simplest setup, open the project in a browser directly:

```text
Open index.html in your browser
```

If you want to serve it locally instead, run:

```bash
npx serve .
```

Then open:

```text
http://localhost:3000
```

## Project Files

- `index.html` — app shell and navigation
- `style.css` — dark theme layout and responsive styling
- `script.js` — app state, rendering, filters, and interactions
- `BUGS.md` — organizer-only documentation for the intentionally planted bugs

## Notes

This app contains intentionally planted bugs for a bug-hunt challenge. Those issues are documented separately in `BUGS.md` and are not shown in the participant-facing interface.
