# Case Files

This project is a small dark-themed detective case board built with plain HTML, CSS, and JavaScript.

## Run locally

Open `index.html` directly in a browser, or run a simple local server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Features

- Top navigation with Overview, Cases, and Suspects
- Search across case titles
- Status filtering for case results
- Case detail view
- Suspect list tied to case data
